The official web platform and developer ecosystem portal for **[RitualDev](https://ritualdev.in)**.

---

## 🚀 Overview
The platform serves as the central hub for RitualDev-Lab's developer security firewalls, monorepo accelerators, and AI tooling:
- **AgentShield**: Runtime security firewall & governance layer for autonomous AI agents.
- **Poly**: Ultra-fast polyglot monorepo build runner & cloud caching engine.
- **DBShield**: Enterprise database security proxy with automated SQL injection defense.
- **FinePrint AI**: High-throughput contract and NDA clause intelligence scanner.
- **MockForge**: Synthetic relational test data generator & mock API engine.

---

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS, responsive dark & light modes
- **Performance**: Edge-rendered via Cloudflare Pages and Workers
- **Type Safety**: Strict TypeScript

---

## 💻 Local Development
```bash
# Clone the repository
git clone https://github.com/RitualDev-Lab/ritualdev-web.git
cd ritualdev-web

# Install dependencies
npm install

# Start local development server
npm run dev
```
Preview at `http://localhost:3000`.
